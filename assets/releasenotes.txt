Release Notes

0.2.0
    * Video scaling (thanks to flexion)
    * --help for common convars (thanks to flexion)
    * a launcher that lets you configure the most common settings
    * lisburn: hardcode DASM and regsiter info to ON since we really don't need them to be an option
    * Allow multibus memory mapping
    * Fix emulator input being sent to main emulator as well as IMGUI
    * Fix shift and ctrl keys 
    * Fix busted back switches impl (was using pm2's???)
    * Last megabyte multibus memory is now emulated
        * It tries to map the last megabyte to a multibus device and treats it as RAM if it fails. Not sure if this is right
    * Multibus devices now use the SlotMapping class instead of the SLot class, they can map any number of regions now instead of being limited to 20 Multibus slots with one mapping each.
    * Memory / VRAM editors (CoherentEditor) now have an ASCII view.

0.1.1 (August 10, 2026)
    * Fixed log file crashing early in initialisation.
        * I forgot that strncpy with overlapping memory is undefined behaviour.
    * Fixed a bug where memory was being incorrectly deallocated.
    * Create the profile folder if it does not exist.
    * Fix many issues with invalid cleanup on shutdown, should fix shutdown crashes.
    * Added a very bad and crude memory / VRAM viewer.
    * Use SDL HiDPI flag on window creation.
    * Add logDC4 convar and suppress DC4 Logging by default 
    * Fix log channels never actually being added
        * Fix custom log channels never being used
    * ASAN -O2 now added by default on debug builds 

0.1.0 (August 9, 2026)
    * Initial release.
    Has CPU, MMU, serial, dip switches, dummy RTC, SRAM, partial multibus, mostly complete UC4, partial DC4 emulation
